# Changelog

## 1.1.3

- Updated documentation.

## 1.1.2

- Improved cleanup of settings and screenshot interface references.

## 1.1.1

- Updated documentation and release packaging.

## 1.1.0

- Added preferences for assigning and clearing the copy-only shortcut.
- Shortcut changes apply immediately; no shortcut is assigned by default.
- Fixed clipboard writes and notifications after disabling during capture.

## 1.0.0

- Added Ctrl + Print Screen to open GNOME’s native overlay in copy-only mode.
- Added a small copy-only indicator.
- Supported selection, screen and window captures.
- Preserved normal Print Screen behavior.
- Initial support for GNOME Shell 51.
