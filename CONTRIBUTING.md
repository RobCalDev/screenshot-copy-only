# Contributing

Report bugs and propose changes at https://github.com/RobCalDev/screenshot-copy-only/issues.

Include your GNOME Shell version (`gnome-shell --version`), distribution,
whether the capture was Selection, Screen or Window, what you expected, and
what happened. Mention other screenshot-related extensions. Share only logs
and images that you are comfortable making public.

Run `make check` before submitting a change. See [the maintainer guide](docs/MAINTAINING.md)
for architecture, manual checks and release instructions. Keep the extension
small; discuss new features before expanding the native overlay.
